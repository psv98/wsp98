# UI kit v3

Ресурси з набору `Bilyi_Superkubok_UI_Kit_v3`, які використовує гра:

- `cards/` — рамки карток шести рідкісностей (SVG). Тексти та логотипи накладаються в DOM.
- `buttons/` — фони кнопок (6 кольорів × 4 стани), розтягуються через `border-image`.
- `panels/` — панелі (dashboard, header, modal, scoreboard, club-tile, winner), також 9-slice.
- `icons/` — іконки рідкісності.
- `backgrounds/` — нічний стадіон (альбомний і портретний) та шар конфеті.
- `branding/` — оригінальні логотипи ІМІ.

Трофей лежить у `public/assets/icons/supercup.webp`. PNG-дублікати, галереї та вихідні ілюстрації з набору до збірки не додаються.
