# Білий суперкубок

Браузерна футбольна аркада та симулятор медіачемпіонату: 18 клубів на основі медіа з Білого списку ІМІ (перше півріччя 2026), 34 тури, 306 матчів за сезон, мегатрансфери персонажів ІМІ, медіакоїни, втома, травми й необмежена кількість сезонів.

> Розважальний вигаданий проєкт. Реальні медіа та співробітники ІМІ — лише основа для фантазійних клубів і персонажів; ігрові характеристики не є оцінкою їхньої роботи.

## Запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev        # режим розробки: http://localhost:5173
npm test           # автоматизовані тести
npm run build      # збірка у теку dist/
npm run preview    # перегляд зібраної версії
npm run balance    # статистика балансу симуляції (необовʼязково: npm run balance -- 200 x)
```

## Розгортання на GitHub Pages

У репозиторії вже є workflow `.github/workflows/deploy.yml`.

1. Злийте код у гілку `main`.
2. У налаштуваннях репозиторію: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Після кожного пушу в `main` workflow запускає тести, збирає гру й публікує `dist/`.

Збірка використовує відносні шляхи (`base: './'` у `vite.config.ts`), тому працює за будь-якою адресою виду `https://<користувач>.github.io/<репозиторій>/` без додаткових налаштувань. Альтернатива без Actions: виконати `npm run build` і опублікувати вміст `dist/` (наприклад, у гілку `gh-pages`).

## Технології та чому саме вони

| Завдання | Рішення | Причина |
|---|---|---|
| Інтерфейс | React 19 + TypeScript + Vite | швидка збірка, сувора типізація |
| Рендеринг матчу | власний рендерер на Canvas 2D | на полі лише 23 спрайти та мʼяч; PixiJS/Phaser додали б сотні кілобайт без виграшу. Статичні шари (поле, трибуни) малюються один раз, спрайти кешуються |
| Звук | Web Audio API, повністю синтезований | жодних аудіофайлів і ліцензійних ризиків; запуск після першого дотику |
| Збереження | IndexedDB (резерв — localStorage) | транзакції, версія схеми, контрольна сума, резервні копії |
| Офлайн | власний Service Worker (`public/sw.js`) | кеш ресурсів, гра без інтернету після першого відкриття |
| Шрифти | Sofia Sans Extra Condensed, Tektur, Golos Text (локально через @fontsource) | кирилиця, спортивний характер, жодних зовнішніх запитів |
| Тести | Vitest + fake-indexeddb | рушій не залежить від DOM, тож тестується в Node |

Розмір зібраного JS — близько 130 КБ (gzip).

```

  assets/stars/     портрети світових зірок
  assets/icons/     supercup.svg — єдине джерело графіки трофея (+ PNG 16–256), іконки застосунку та рідкісності
  assets/audio/, assets/effects/   зарезервовано для власних ресурсів
  sw.js, manifest.webmanifest
src/
  data/             конфігурації: balance.ts (УСІ числа балансу), clubs.ts, specials.ts, rarity.ts, formations.ts
  simulation/       рушій матчу: engine.ts (фізика, правила), ai.ts (ШІ гравців), restarts.ts (стандарти), rng.ts, types.ts
  systems/          чемпіонат: schedule, table, squad, transfers, economy, season, actions
  storage/          db.ts — IndexedDB, перевірка, експорт/імпорт
  game/             store (стан і автозбереження), renderer (Canvas), audio, commentary, selectors
  components/       екрани та компоненти інтерфейсу; cards.tsx — єдина система карток;
                    supercup.tsx — SupercupIcon, SupercupLogo, ChampionshipBadge, VictoryScreen, TrophyRevealAnimation
  styles/           tokens.css (дизайн-система), app.css, cards.css, arcade.css (аркадний стиль і айдентика кубка)
tests/              автоматизовані тести
scripts/            balance.ts — масова симуляція для перевірки балансу
```

## Як замінити логотипи та інші ресурси

- **Логотип клубу:** замініть файл `public/assets/clubs/<id>.png` файлом із тією самою назвою (квадратний PNG, бажано 256×256, логотип у колі або на прозорому тлі). Ідентифікатори: `suspilne, espreso, babel, svoboda, hromadske, pravda, nv, texty, lb, ukrinform, graty, hromradio, tyzhden, dzerkalo, rubryka, slovoidilo, novynarnia, frontliner`.
- **Логотип ІМІ:** `public/assets/imi/imi.png` (картки), `imi-user.png` та `imi-opp.png` (фішки на полі).
- **Трофей:** `public/assets/icons/supercup.svg`. Після зміни перегенеруйте PNG-версії (16, 32, 64, 128, 256 px) будь-яким конвертером SVG → PNG.
- **Зірки:** `public/assets/stars/{messi,ronaldo,neymar,buffon}.png`.
- **Назви, описи, сила клубів:** `src/data/clubs.ts`. **Персонажі та здібності:** `src/data/specials.ts`. **Кольори й іконки рідкісності:** `src/data/rarity.ts` та `src/styles/tokens.css`.
- **Будь-які числа балансу** (тривалість тайму, шанси, ціни, нагороди): `src/data/balance.ts`.
- Після заміни ресурсів у вже опублікованій грі змініть назву кешу `CACHE` у `public/sw.js` (наприклад, `bsk-v2`), щоб гравці отримали нові файли.

## Реалізовані можливості

- **Повний цикл:** титульний екран → вибір одного з 18 клубів → панель менеджера → склад і тактика → матч → підсумки туру → мегатрансфер → наступний тур → церемонія після 34-го туру → наступний сезон або скидання.
- **Матч:** вигляд строго зверху, 22 гравці, арбітр, окремий мʼяч із фізикою (ведення, короткі й верхові передачі, перехоплення, відбори, удари, відскоки, сейви, блоки, стійки). Аути, кутові, удари від воріт, штрафні, пенальті, гра головою. Рахунок змінюється лише тоді, коли мʼяч перетинає лінію воріт.
- **Тривалість:** два тайми по 90 секунд (45 ігрових хвилин кожен) плюс короткі паузи на події; є прискорення ×2/×4 і миттєвий результат (той самий рушій).
- **ШІ за ролями:** воротар, центральні й крайні захисники, опорні, центральні та атакувальні півзахисники, вінгери, нападники; схеми 4-3-3, 4-4-2, 4-2-3-1, 5-3-2; пресинг, опіка, відкривання, забігання.
- **Менеджер:** заміни (до 5, під час зупинок гри), зміна схеми під час матчу, автосклад; вилученого гравця замінити не можна, команда перебудовується в меншості.
- **Дисципліна:** фоли, жовті, друга жовта, пряма червона, дискваліфікації (у т. ч. за 4 жовті).
- **Втома і травми:** витривалість 0–100 %, поступове виснаження за 3–4 матчі, вплив на швидкість і точність, травми на 1–5 матчів, лікування та відновлення за медіакоїни.
- **Мегатрансфери:** 14 персонажів ІМІ шести рівнів рідкісності, гарантія випадіння не пізніше третього матчу, без дублікатів, комплекти «Аналітичне супертріо» та «Юридичне мегадуо» (взаємовиключні в межах сезону), «сюжетні переходи» від суперників, кінематографічне відкриття карток.
- **Здібності:** різна сила в клубі користувача та суперника; спрацьовують лише за ігрових умов (позиція, володіння, дистанція). «Повітряний штурм Ісиченка», «Юридичний VAR», «Золота хвилина», «Остання атака», «Сенсація туру», «Травма зірки», «Герой матчу».
- **Оксана Романюк** завжди починає в «Суспільне Юнайтед» (приєднується до нього з 5-го туру) і до вас переходить саме звідти. Якщо ви самі керуєте «Суспільним», вона зʼявляється у вас як вихованка клубу.
- **Айдентика:** власний векторний трофей із мʼячем, емблема гри, позначка чемпіона, анімація вручення кубка та святковий екран «ВИ — ЧЕМПІОНИ!».
- **Суперники** отримують персонажів із 5-го туру (з попередженням перед матчем), а з 2-го сезону — й світових зірок.
- **Економіка:** медіакоїни за результати та досягнення, журнал операцій, «Фінансовий джекпот ІМІ» відкриває ринок (Мессі, Роналду, Неймар, Буффон).
- **Чемпіонат:** двоколовий календар, таблиця (очки → різниця → забиті), результати всіх матчів, статистика й архів сезону, історія сезонів.
- **Збереження:** автозбереження після кожної дії, версія схеми, контрольна сума, відновлення останнього коректного стану, експорт/імпорт JSON, відновлення початку сезону, подвійне підтвердження скидання.
- **Звук:** оригінальна музика меню, трибуни зі скандуванням, свисток, удари, голи, картки, теми карток і церемонії; окремі регулятори гучності та вимкнення.
- **Адаптивність:** телефони, планшети, компʼютери; на вертикальному екрані поле повертається, є повноекранний режим; режим зниженої якості графіки.

## Результати тестування

`npm test` — 44 тести, усі проходять:

- **Календар і таблиця:** 34 тури × 9 матчів = 306, кожен із кожним удома й на виїзді, без повторів у колі; очки та сортування.
- **Симуляція:** детермінованість, рахунок = кількість зафіксованих голів, тривалість матчу, не більше 11 гравців і одного воротаря, вилученого не замінюють, ліміт замін, втома.
- **Здібності:** Оксана 100 % / 50 %, Ігор 90 % / 45–50 %, бонус супертріо, VAR не більше разу, «Повітряний штурм» лише за активної події та кутового.
- **Економіка і трансфери:** нарахування, заборона витрат понад баланс, закритий ринок без джекпоту, гарантія випадіння, рідкісність, відсутність дублікатів, взаємовиключення комплектів, унікальність персонажів.
- **Сезон:** повні 34 тури на справжньому рушії, неможливість повторно застосувати тур чи двічі отримати картку, наступний сезон.
- **Збереження:** запис/читання, відновлення пошкодженого запису, відмова записати некоректний стан, експорт/імпорт.

Додатково гру пройдено в браузері автоматичним сценарієм (повний сезон, церемонія, наступний сезон, перезавантаження сторінки) на екранах компʼютера та телефона — без помилок у консолі.

Орієнтири балансу (`npm run balance`): близько 3 голів за матч; явний аутсайдер перемагає фаворита приблизно у 14–19 % матчів.

## Відомі обмеження

- **Офсайду як правила немає.** Нападники самі тримаються лінії останнього захисника, але арбітр офсайд не фіксує.
- **Незавершений матч не зберігається.** Якщо закрити вкладку під час матчу, його доведеться зіграти заново (нагороди при цьому не дублюються).
- **Оксана Романюк у клубі користувача дуже сильна:** середній клуб із нею виграє близько 95 % матчів. Це наслідок вимоги про 100 % реалізації; параметри легко послабити в `src/data/specials.ts`.
- **Звук синтезований**, тому простіший за студійні записи.
- Гру перевірено автоматично в Chromium; на реальних iPhone/iPad і в Safari вручну не тестувалося.
- Очищення даних сайту в браузері видаляє прогрес — користуйтеся експортом у файл.
